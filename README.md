# Testes de Software em E-commerce

## Sobre o projeto

Este projeto tem como objetivo aplicar conceitos de Quality Assurance (QA) por meio de testes manuais em uma aplicação de comércio eletrônico.

Serão desenvolvidas atividades de planejamento, elaboração, execução e documentação de testes, com foco na identificação de falhas e na validação das principais funcionalidades do sistema.

## Aplicação em teste

**Nome:** SauceDemo

**Acesso:** https://www.saucedemo.com/

## Escopo dos testes

- Autenticação de usuários
- Listagem de produtos
- Ordenação de produtos
- Adição e remoção de produtos do carrinho
- Processo de checkout
- Finalização de pedidos

## Atividades desenvolvidas

- Elaboração do plano de testes
- Criação de casos de teste
- Testes funcionais
- Testes positivos e negativos
- Identificação e documentação de bugs
- Registro de resultados e evidências

## Ferramentas e tecnologias

- Git e GitHub
- Markdown
- SQL (em desenvolvimento)
- Ruby e Capybara (automação futura)
