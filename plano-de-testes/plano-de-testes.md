## 2. Objetivo

Validar o funcionamento das principais funcionalidades da aplicação SauceDemo, identificando possíveis falhas e verificando se o comportamento do sistema está de acordo com os resultados esperados.

## 3. Escopo dos testes

### Funcionalidades incluídas

- Login e autenticação de usuários.
- Visualização e listagem de produtos.
- Ordenação de produtos.
- Adição e remoção de produtos do carrinho.
- Preenchimento dos dados de checkout.
- Finalização de pedidos.

### Funcionalidades não incluídas

- Testes de desempenho.
- Testes de segurança avançados.
- Testes de compatibilidade entre navegadores.
- Testes de integração com sistemas externos.

## 5. Estratégia de testes

Serão realizados testes manuais utilizando cenários positivos e negativos.

Os testes positivos verificarão se o sistema funciona corretamente quando recebe informações válidas.

Os testes negativos verificarão como o sistema reage a informações inválidas, campos vazios e situações inesperadas.

Cada teste terá:
- Identificação.
- Descrição.
- Pré-condições.
- Passos para execução.
- Resultado esperado.
- Resultado obtido.
- Status.

## 6. Critérios de aprovação

Um caso de teste será considerado aprovado quando o comportamento observado corresponder ao resultado esperado.

Caso exista divergência entre o resultado esperado e o comportamento apresentado, o teste será considerado reprovado e a ocorrência será analisada.

## 7. Critérios de encerramento

A etapa de testes será considerada concluída quando:

- Todos os casos de teste planejados forem executados.
- Os resultados forem documentados.
- As falhas identificadas forem registradas.
- As evidências disponíveis forem organizadas.

## 8. Riscos

- Indisponibilidade da aplicação.
- Alterações no funcionamento da aplicação durante os testes.
- Limitações dos usuários de demonstração.
- Falhas que dependam de condições específicas para reprodução.

## 9. Observações

Este projeto possui finalidade educacional e será desenvolvido para praticar conceitos de Quality Assurance e documentação de testes de software.
